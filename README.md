# MAUS HRV — Cognitive Load Classification

A complete Java machine learning pipeline that classifies cognitive load levels (0-back, 2-back, 3-back) from Heart Rate Variability (HRV) features extracted from the MAUS dataset, with results presented through an interactive JavaFX dashboard.

---

## Overview

Mental workload estimation is useful in human-computer interaction, driver monitoring, adaptive learning, and safety-critical systems. This project estimates cognitive load from heart rate variability patterns recorded during n-back tasks. It converts raw Inter-Beat Interval (IBI) sequence files into compact statistical HRV features and applies supervised machine learning to classify each trial's cognitive load level.

The system has two outputs:

1. A structured dataset — `final_dataset.csv` — containing nine HRV features and a cognitive load label per trial.
2. A JavaFX dashboard presenting model accuracy, per-class metrics, confusion matrices, feature importance, and class distribution.

---

## Dataset

This project uses IBI sequences from the **MAUS (Multimodal Affect and Usability Study)** dataset. Participants completed an n-back working memory task across six trials:

| Trial | Condition | Label |
|---|---|---|
| 1, 6 | 0-back (baseline) | 0 |
| 2, 4 | 2-back (moderate load) | 2 |
| 3, 5 | 3-back (high load) | 3 |

The final processed dataset contains **396 instances**, perfectly balanced across all three classes (132 per class).

## Architecture

The pipeline is divided into five stages, each handled by a dedicated class:

| Component | Responsibility |
|---|---|
| `Main.java` | Builds `final_dataset.csv` from participant IBI files and computes HRV features. |
| `DatasetAnalyzer.java` | Reports class distribution and per-class feature means. |
| `ModelEvaluation.java` | Runs Weka model evaluation from the command line and prints metrics. |
| `ModelEvaluationWithStore.java` | Runs the same model evaluation and stores dashboard-ready results. |
| `ResultsStore.java` | Singleton in-memory store for model metrics, confusion matrices, feature importance, and class distribution. |
| `DashboardApp.java` | JavaFX entry point with background model training and a loading screen. |
| `DashboardController.java` | Builds the dashboard tabs — Overview, Per-Class Metrics, Confusion Matrix, Feature Importance, and Class Distribution. |

This separation keeps data processing, machine learning, and presentation logic independent, so the same evaluation code can be run either from the command line (`ModelEvaluation`) or from the JavaFX dashboard (`ModelEvaluationWithStore`) without duplication.

## HRV Feature Extraction

`Main.java` traverses `data/IBI_sequence`, reads each trial's raw IBI values, filters out physiologically implausible readings (outside 300–2000 ms), and computes nine time-domain HRV features per trial:

| Feature | Meaning |
|---|---|
| `MeanIBI` | Mean inter-beat interval, in milliseconds. |
| `MeanHR` | Mean heart rate, computed as `60000 / MeanIBI`. |
| `SDNN` | Standard deviation of normal-to-normal IBI values. |
| `RMSSD` | Root mean square of successive IBI differences. |
| `SDSD` | Standard deviation of successive IBI differences. |
| `NN50` | Count of successive IBI differences exceeding 50 ms. |
| `pNN50` | `NN50` expressed as a percentage of successive intervals. |
| `MinIBI` | Minimum valid IBI value within a trial. |
| `MaxIBI` | Maximum valid IBI value within a trial. |

Trial labels are derived from the fixed MAUS task sequence using exact numeric trial-index parsing — not string prefix matching — to avoid mislabeling trials such as `trial_10` as `trial_1`.

## Machine Learning Methodology

Built on **Weka 3.8.6**. After loading `final_dataset.csv`, the `Subject` and `Trial` columns are removed (identifiers, not predictors), the class attribute is converted from numeric to nominal, and all features are normalized to `[0, 1]` using Weka's `Normalize` filter — critical for the Multilayer Perceptron and applied consistently across all models for a common evaluation input.

| Model | Configuration |
|---|---|
| Random Forest | 100 trees, seed 1 |
| Multilayer Perceptron | Seed 1, 200 training epochs |
| AdaBoostM1 | `DecisionStump` base learner, 50 boosting iterations |

Each model is evaluated using:
- **Stratified 10-fold cross-validation** (fixed seed for reproducibility)
- **80/20 held-out test split** (fixed seed for reproducibility)

Reported metrics: **Accuracy, Cohen's Kappa, MAE, RMSE**, plus **per-class Precision, Recall, and F1-score**, and the full **confusion matrix**.

Feature importance is ranked using **Information Gain** via Weka's `AttributeSelection` + `InfoGainAttributeEval` + `Ranker`.

---

## Dashboard

`DashboardApp.java` launches a JavaFX window that trains all three models on a background thread (with a loading spinner) and then displays a five-tab results dashboard:

1. **Overview** — accuracy bar chart (color-coded by threshold) + summary metrics table (Accuracy, Kappa, MAE, RMSE)
2. **Per-Class Metrics** — Precision / Recall / F1 bar chart with a model selector dropdown
3. **Confusion Matrix** — interactive table with diagonal (correct predictions) highlighted
4. **Feature Importance** — Information Gain ranking as a bar chart
5. **Class Distribution** — pie chart of label counts and percentages

## Setup

### 1. Clone the repository

```bash
git clone https://github.com/bilalegl/maus_project.git
cd maus_project
```

### 2. Download JavaFX 21 SDK

Download from [Gluon](https://gluonhq.com/products/javafx/) and extract to a known path, e.g. `C:\javafx-sdk-21`.

### 3. Install dependencies

```bash
mvn dependency:copy-dependencies -DoutputDirectory=target\dependency
```

---

## Usage

### Step 1 — Generate the dataset

Place raw IBI sequence folders under `data/IBI_sequence/<subject_id>/trial_<n>.csv`, then run:

```bash
mvn compile exec:java -Dexec.mainClass="com.maus.Main"
```

This produces `final_dataset.csv` in the project root.

### Step 2 — (Optional) Inspect the dataset

```bash
mvn compile exec:java -Dexec.mainClass="com.maus.DatasetAnalyzer"
```

Prints total row count, class distribution, and per-class feature means.

### Step 3 — Run the dashboard

```bash
java --module-path "C:\javafx-sdk-21\lib" --add-modules javafx.controls,javafx.fxml -cp "target\classes;target\dependency\*" com.maus.DashboardApp
```

The dashboard will train all three models in the background, then display the full results UI.

### Alternative — command-line evaluation only

```bash
mvn compile exec:java -Dexec.mainClass="com.maus.ModelEvaluation"
```

Prints 10-fold CV results, held-out split results, and feature importance directly to the console — no JavaFX required.

| Multilayer Perceptron | Gradient-based; benefits most from normalization. |
| AdaBoostM1 | Sequential boosting of weak Decision Stump learners. |

*(Run the project on your own dataset to populate exact accuracy, Kappa, and confusion matrix values.)*

Class distribution is perfectly balanced (132 / 132 / 132), so Accuracy and Kappa are expected to track closely, with any divergence indicating asymmetric error concentration between specific class pairs (e.g., 2-back vs. 3-back) rather than overall majority-class bias.

## Limitations and Future Work

- Only time-domain HRV features are used; frequency-domain features (LF/HF ratio, total power) may capture additional autonomic information.
- Evaluation uses random 10-fold CV and an 80/20 split rather than leave-one-subject-out cross-validation, which would more rigorously test generalization to unseen subjects.
- Deep learning approaches (e.g., LSTM on raw IBI sequences) may capture temporal dynamics lost in aggregated feature extraction.
